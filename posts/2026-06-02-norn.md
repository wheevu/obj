`norn`, a small C++ concurrency runtime built around task stealing and a hand-rolled scheduler.
It exists because I wanted to understand how work actually moves between threads without trusting a black box to do it for me.

It is still going: still compiles, still taught me something this quarter, still has at least one bug I have not found.
The hard part is the usual one: memory reclamation under concurrent access, and the current answer is hazard pointers, not garbage collection.
The repository is public; the warranty is not.
