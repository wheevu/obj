# obj

my blog place! I write about life and things

A small Lua site builder turns Markdown posts into the site at [wheevu.github.io/obj](https://wheevu.github.io/obj/).

I mostly made it because I wanted an excuse to use Lua :p

- Write through a local browser editor
- Build the static site with Lua
- Publish through GitHub Pages
- Keep every post as plain Markdown

[Setup, commands, and post format](GUIDE.md).
